# 💰 情報コンテンツ販売 (AIマネタイズ・外貨獲得ノウハウ)

## 事業の目的
「神仏アートの描き方」のような趣味の講座ではなく、現在の市場で爆発的に需要のある「AIマネタイズ」と「海外からの外貨獲得」に直結する**稼ぐためのノウハウ（実利）**を教材化し販売する。GodWorksが持つ海外バズの実績と、越境ECでの販売実績を「証拠」として提示することで、高単価でも飛ぶように売れる商品を作る。

## プラットフォーム展開

### 1. Brain / Tips (国内向けマネタイズ教材)
- **商品の毛色**: 「AI×和風クリエイティブで越境ECから外貨を稼ぐ完全ロードマップ」や「顔出し不要！海外TikTokバズのアルゴリズムハック」。表現ではなく「稼ぎ方」を売る。
- **必要なアセット**:
  - Etsy等のプラットフォームでの具体的な売上実績、TikTokの数百万再生のアナリティクス画像（権威性の証明）
  - AI（Midjourney等）を用いて外国人ウケする和風アセット（サイバー仏教等）を量産する具体的なプロンプト集
  - 無在庫・自動ダウンロード納品を構築するまでのステップバイステップ解説
- **目標収益**: 単価 ¥30,000〜50,000 × 月間 10人 = ¥300,000〜500,000

### 2. Teachable (海外向け動画コース)
- **商品の毛色**: 「How to create Cyber-Buddhism Art」「Japanese Shinto Design Masterclass」など、日本の美を学びたい海外クリエイター向けの英語動画コース。
- **必要なアセット**:
  - 英語字幕付きのチュートリアル動画パッケージ
